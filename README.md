# My Life Calendar

Автоматический генератор календаря года в виде обоев для телефона. Каждый день создаётся новая картинка, показывающая, сколько времени прошло и сколько осталось до конца года.

## 🎯 Что это?

Минималистичный календарь, который:
- Показывает все 12 месяцев в виде точек
- Белые точки — прошедшие дни
- Оранжевая точка — сегодня
- Серые точки — будущие дни
- Показывает, сколько дней осталось и какой процент года прошёл

## ⚙️ Как это работает

1. **GitHub Actions** каждый день в 23:00 (МСК) запускает скрипт
2. Скрипт генерирует PNG-изображение с актуальным календарём
3. Картинка сохраняется в репозитории и доступна по ссылке
4. На iPhone настраивается автоматизация в приложении **Команды** (Shortcuts), которая каждое утро скачивает свежую картинку и ставит на обои

## 📱 Как использовать

### 1. Склонируй репозиторий или создай свой

### 2. Настрой автоматизацию на iPhone:
- Открой приложение **Команды** → **Автоматизация**
- Создай новую автоматизацию по времени (например, 08:00)
- Добавь действия:
  - **Получить содержимое URL**: `https://твой-username.github.io/my-life-calendar/calendar.png`
  - **Установить обои** → выбери полученное изображение
- Выключи **"Спрашивать до запуска"**

### 3. Готово!
Теперь каждое утро у тебя будут свежие обои с актуальным календарём
